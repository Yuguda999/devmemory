## Slide 2: Project Identity

**DevMemory** is a persistent memory layer for AI coding tools. It stores, structures, and serves your coding context so any AI tool can pick up exactly where the last one left off — no re-explaining, no lost momentum.

## Slide 3: What the Product Does

Show the user-facing problem and the product in plain language.

**The problem**
Every time you switch AI coding tools — Cursor → Claude → Windsurf — your context dies. You restart from scratch, re-explain the goal, re-paste the same snippets, and lose momentum. Credit/quota resets force the same tool-hop, with the same loss.

**Who the user is**
Developers who code with AI assistants and use more than one tool (Claude Code, Cursor, Windsurf, Antigravity, Codex). Solo builders, freelancers, and small teams who switch tools by task, cost, or credit limits.

**What the user can do**
- Install one client (`npx` or `pip`) that wires DevMemory into every AI tool.
- Automatically save goals, decisions, code changes, errors, and next steps as they work — no manual prompting (OS-level hooks + a watch daemon capture context deterministically).
- Switch tools mid-project and have the new tool auto-load the full prior context.
- Track tasks and generate a tuned "continue here" resume prompt for the target tool.
- Monitor sessions, projects, and connected tools from a web dashboard.

**What value the user gets**
Continuous context across tools and across credit resets. One project, one memory, zero friction. Work survives the tool switch.

**Where payment happens**
In the hosted web dashboard, under **Billing**. Free / Pro / Team tiers. Upgrades are paid **in ADA on Cardano** — the dashboard issues an on-chain invoice and unlocks higher project/session/context limits on payment.

4. **Payment gate** — hit the Free-tier limit (10 projects / 30 sessions per project) → Billing → **Upgrade to Pro**.
5. **Delivered result after payment** — pay the ADA invoice on Cardano → tier upgrades → higher limits unlock immediately; dashboard reflects new plan and quota.

## Slide 5: How a User Buys the Product

The product is a **freemium hosted SaaS with on-chain (Cardano/ADA) upgrades**.

- **Free** — get started at no cost: 10 projects, 30 sessions/project.
- **Pro** — for active solo builders: 25 projects, 100 sessions/project.
- **Team** — for teams: unlimited projects and sessions.

Buy flow: Dashboard → **Billing** → choose **Pro** or **Team** → server issues a Cardano **ADA** invoice → user pays on-chain → tier and limits upgrade automatically.

The client (MCP server + CLI) is free and open-source on npm and PyPI. Revenue comes from hosted-backend tier upgrades.
